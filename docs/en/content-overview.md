# MobChatter

[中文](../content-overview.md)

Many authors have tried to let players talk with mobs — some use hand-written lines, others use live AI. This mod takes a third approach: AI-preset dialogue.

The mod ships with a large library of mob lines generated ahead of time for popular mods. They are played at suitable moments, with more than ten lines per scenario selected at random, for roughly **one million** lines in total.

To build that library, the project collected the **308** most-downloaded mods that add mobs and extracted information for **6,507** entity types, including vanilla. See the [supported mods list](https://github.com/The-Stray-Moon/MobChatter/blob/main/docs/supported-mods.md) and the [supported mobs list](https://github.com/The-Stray-Moon/MobChatter/blob/main/docs/supported-mobs.md).

For each entity, more than ten lines were generated for 21 common, universal mob behavior scenarios, weighted by how often each scenario occurs:

Everyday behavior (11): `walk`, `idle`, `look_player`, `tempted`, `collide`, `mate`, `pickup`, `target_acquire`, `targeting`, `melee_attack`, `spawn`.

Damage (10): the generic `hurt`, plus nine specific cases: `hurt.fire`, `hurt.fall`, `hurt.drown`, `hurt.explosion`, `hurt.projectile`, `hurt.magic`, `hurt.starvation`, `hurt.lightning`, `hurt.void`.

The build contains **998,401** source line pairs. Per-entity dialogue sources live in [`dialogue-pack/`](../../dialogue-pack/); the runtime resource is `dialogue.json.xz`.

The server watches mob behavior, picks a matching line at random, and broadcasts it to every player within range, so all nearby players see the same line above the same mob.

![showcase](https://resource-api.xyeidc.com//client/members/pics/2af9d9e9)

Ten-plus lines per scenario is already plenty in normal play. If you want more, add your own through a resource pack, for example `assets/alexsmobs/mobchatter/dialogue/grizzly_bear.json`:
```
{
  "format_version": 1,
  "mode": "merge",
  "scenarios": {
    "walk": {
      "operation": "append",
      "lines": [
        {
          "zh": "这边的草好像更香。",
          "en": "The grass smells better over here."
        }
      ]
    },
    "look_player": {
      "operation": "replace",
      "lines": [
        {
          "zh": "你带小麦了吗？",
          "en": "Did you bring any wheat?"
        }
      ]
    }
  }
}
```

The mod also adds a headwear item called the Radio Receiver. When `requireReceiver` is enabled in the config, only players wearing it can see mob chatter.

The built-in lines were generated by DeepSeek and can feel a little rough. Contributions of new lines are welcome.
